# TASK120 — Банк вопросов, быстрое сохранение и история шаблонов

Базовая ветка: TASK119 (Draft PR #105). В TASK120 действующий редактор
диагностик расширяется **без смены формата QDIAG/QTPL** и без вмешательства
в редакторы таблиц, презентаций и Студии.

## 1. Общий банк
- Собирает задания из 19 встроенных диагностик, **дедуплицируя по предмету,
  классу и нормализованной формулировке**. Исходные встроенные материалы
  не меняются; предзаполненные ответы остаются доступны преподавателю.
- Личный банк хранится отдельно в localStorage под собственным ключом,
  ограничен 500 вопросами.
- Фильтры предмета, класса, типа и строковый поиск по вопросу, теме,
  эталонному ответу. По 20 результатов на страницу.
- Добавление вопроса копирует тип, варианты, эталон, числовую погрешность,
  баллы. Всегда создаётся **новый ID**. Можно выбрать существующий раздел
  либо раздел из банка. Если он отсутствует, создаётся новый в рамках
  действующих лимитов 24 раздела / 240 заданий.
- Повторы в текущей диагностике блокируются по нормализованной
  формулировке, а не только по ID.
- Кнопка «Сохранить вопрос в банк» находится в развернутой карточке
  конструктора; сведения об ученике, сессии и результатах не переносятся.
- Личный банк переносится через **.qbank**. Импорт проверяет версию,
  структуру, лимит и существующие вопросы; некорректные файлы
  не записываются.

## 2. Сохранение без прокрутки
- Вверху конструктора есть компактная липкая полоса:
  «Сохранить шаблон» и «Банк вопросов».
- Первое сохранение текущей встроенной диагностики создаёт **личную копию**,
  а не меняет встроенную.
- После создания своей копии последующее сохранение в рамках текущей
  работы обновляет её; при смене названия совпадающий сторонний шаблон
  не перезаписывается автоматически.
- Статус «Локальный черновик» / «Все изменения сохранены в шаблоне»
  сравнивает учебное содержимое, а не журнал учеников.
- Существующий подробный блок внизу конструктора остаётся для
  назначения предмета, класса, цели и явного выбора шаблона.

## 3. История изменений шаблонов
- Перед изменением существующего пользовательского шаблона сохраняется
  его предыдущая версия (до **5** версий на шаблон, отдельно от QTPL).
- В нижнем блоке можно выбрать старую версию и восстановить её
  **в пользовательской библиотеке** после подтверждения. Текущая
  рабочая диагностика при восстановлении **не изменяется**.
- Если не удалось сохранить резервную версию из-за ограничений браузера,
  перезапись шаблона блокируется.
- Для переноса истории между устройствами механизма пока нет.
  QTPL переносит актуальные шаблоны, QDIAG — диагностику, QBANK —
  личные вопросы. Рекомендуется скачивать файлы для резервного хранения.

## 4. Проверки и ограничения
- `tests/task120.test.js`: доступность встроенных вопросов,
  независимое копирование, дедупликация, личный банк, импорт,
  накопление 5 версий и восстановление без изменения текущего документа.
- `tests/task120_browser.cjs`: фильтры и UI вставки, сохранение,
  статус черновика, два последовательных сохранения, восстановление,
  экспорт и компоновка на экранах 1600/1100/650/390 px.
- `npm test`, `npm run build`, Chromium smoke.
- Нет автоматической отправки каких-либо данных в сеть.
- **Ещё не реализовано в TASK120:** облачная синхронизация, редактирование
  встроенных вопросов напрямую, сложная таксономия знаний, генерация
  новых вопросов моделью, распределение по ученикам и полноценная
  система автоматической повторной проверки.
