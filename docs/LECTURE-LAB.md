# Lecture lab — isolated foundation, owner clarification
This is a document/material preparation workspace, NOT a video editor. Lecture and script are two views of one document; the latter has cumulative estimated time intervals and collapsible semantic blocks. Existing Office launcher and native installers are untouched. Current experimental preview: lecture-lab/Quantum-Lectures.html (open locally, no network).
QLECTURE v2 imports v1 without losing original scene text, notes or figure descriptions. v2 adds mode and typed visual snapshots: diagrams (rect, circle, line, text), graph models with editable labels/colors/parameters. Explicit import/export only; no native storage or backup integration, no claim of durable autosave. Each seed section has an actual visual; original planned figures not all realized yet, narration remains condensed.
Inline editing via property fields: coordinates, sizes, colors, text, add/delete shapes; graph parameters, progress, playback/pause/reset. SVG and 1440×800 PNG for individual visuals, including current graph frame. No video timeline, audio, WebM/GIF export, arbitrary JS, drag selection, undo or reusable library yet. Graph animation is local preview, not a downloadable animation. Exported PNG/SVG static; board import compatibility not tested.
Standalone browser smoke: node tests/lecture-lab-browser.mjs after npm ci and Chromium installation. Pure tests run under npm test. No edits to production shell, build script, existing CI or storage. Standalone HTML generated from module sources; verify script compares exact generated result. Later integrate route and shared graphics editor via adapters when installer accepted. 

Follow-up: the lab adds selection of individual SVG elements by clicking and a browser-dependent six-second WebM export of individual graph animations (not lecture recording); no audio or video timeline.
