# TASK114 — История знаний учеников

## Цель

Продолжить работу над диагностикой после TASK113, используя полезные функции без повторного переполнения рабочей области. Основная широкая компоновка и лента TASK112 не меняются.

## Реализовано

В Тексты → Диагностика → Проведение → Журнал результатов при выборе ученика появилась отдельная карточка «Динамика занятий».

- Последние восемь сохранённых проверок показаны компактной гистограммой процентов.
- Можно выбрать две конкретные проверки и увидеть изменение результата в процентных пунктах (п.п.).
- Для совпадающих названий тем сравниваются сохранённые тематические проценты; в каждой строке видны исходный и новый результат и их разница.
- Если число оценённых заданий либо общее число вопросов различается, появляется предупреждение «Разное число заданий». Темы без оценённых заданий не сравниваются.
- Отдельная кнопка «Сравнение CSV» выгружает только выбранную пару занятий и общие темы, без ответов или истории других учеников; ячейки экранируются от CSV-формул.
- Если у выбранного ученика менее двух проверок, выводится пояснение вместо пустого графика.
- История читается из сохранённых снимков занятия (`summary`, `topics`), а не пересчитывается по изменившемуся впоследствии словарю вопросов.
- Используется существующий фильтр по профилям учеников. Данные остаются локальными; никаких внешних запросов.

Отдельный график расположен в журнале, а не в правой боковой панели, где TASK113 показывает текущую очередь проверки. Плиточная лента, ширина вопросов, экспорт QDIAG и все остальные редакторы не изменяются.
