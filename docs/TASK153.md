# TASK153 — компактный печатный сборник по референсу владельца

Статус: отдельная итерация в `feat/task153-exam-booklet-pdf`. База — HEAD TASK152.0 `60cac825a0aac04c8f5105c41e5d8843fb36043e`; PR направлен в `feat/task152-diagram-tools`, поскольку TASK152.0 пока Draft и не в main. Merge запрещён без разрешения.

## Задача и исходный ориентир

Референсы владельца (три скриншота экзаменационных страниц, 18.11.2026): высокая плотность заданий, книжная типографика, прямоугольные номера, читаемые формулы, схемы рядом с условием, аккуратные ответы, нумерация страниц. Чужой логотип/соцссылки не копируются. Автоматически отделять «часть 1» от «части 2» не требуется: это отдельная задача банка.

## Сделано

- Новый необязательный `booklet` / «Экзаменационный сборник» поверх существующей модели QWORK v1. Старые `compact`, `practice`, `worksheet`, `exam` не подменяются.
- Книжный шрифт `QO Print Serif` с OFL-лицензией уже встроен в автономный HTML. 10,5 pt по первому выбору; редактируемо в пределах 9–12 pt, без скачивания шрифтов.
- Задания: рамка номера 10×6,7 мм, сквозная нумерация, компактная полоса 5 мм между блоками; строки ответа только для применимых типов при `answerVisible=true`. Без принудительной разлиновки.
- Отдельная центральная строка «Вариант №…» если вариант задан, заголовок по названию проекта, нижний колонтитул без ссылки/логотипа, только страница.
- Вариант оформляется без автоматически вставляемых разделов по `part`. Пользовательские `pageBreak` остаются в силе.
- А4: поля 13 мм слева/справа, 13 мм сверху, 17 мм снизу, печатная область 184×267 мм. Плотная автоматическая пагинация существующего `qwPreparePrintDocument`.
- Рисунки SVG остаются векторными, встроенные формулы MathML и текст печатаются через HTML → браузерный PDF, без JPEG-страниц. Графики и схемы расположены справа или снизу согласно уже существующим настройкам.
- Режим присутствует в настройках работы и карточках предпросмотра; из «Скачать PDF» попадает в качественную векторную печать.

## Проверка

- `npm test`, `npm run build`.
- `node tests/task153_browser.cjs` создаёт 16 смешанных заданий и 2 SVG-рисунка в реальном офлайн-Chromium, проверяет сохранность QWORK, отсутствие автоматических частей, наличие рамок, нумерацию, выход за страницы, пересечения текста с рисунками, PDF, старый compact.
- Независимый CI-job `task153-booklet` выдаёт PDF, QWORK, PNG, отчёт и автономный HTML.
- Местная проверка аналогичного набора: **16 заданий на двух страницах A4**, PDF сохраняет выделяемый текст (извлечено 1149+851 символов); PDF 120596 байт.

## Известные ограничения

- Пользователь в браузерном режиме выбирает «Сохранить как PDF» в системном диалоге печати; прямое one-click сохранение выделяемого векторного PDF ещё не реализовано.
- Учитывается реальная высота заданий, но алгоритм не занимается глобальным оптимальным распределением для равного заполнения всех страниц.
- Ограниченный язык формул TASK144, не полноценный LaTeX. Пользовательские растровые изображения остаются растровыми; собственные графики/схемы векторные.
- Реальное открытие файла двойным щелчком на Windows владельцем требует отдельной проверки, Chromium CI не заменяет такую приёмку.
