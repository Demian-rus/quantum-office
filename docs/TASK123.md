Информатика**. Из стандартных элементов выбора библиотеки, редактора

localStorage не удаляются; существующие старые метаданные остаются в
файлах до редактирования владельцем.

Встроенный каталог — прежние 14 предметных диагностик, без изменения
самих заданий. Это намеренно единственный источник доступных предметов.

## Новый переносимый файл преподавателя
**Таблицы → лист «Ученики» → панель «Ученики» → «Резервная копия».**

- **Скачать проект**: один файл `.qteacher` (JSON) с полной текущей
  *подключённой* рабочей книгой QBOOK, контактными ссылками и общим
  журналом результатов, относящихся к этому листу.
- **Восстановить проект**: выбирает файл `.qteacher`, проверяет
  формат, версию и QBOOK-схему, подтверждает действие, создаёт
  **отдельную новую книгу** и переназначает ссылки результатов к ней.
  Исходные книги и старый журнал остаются.
- Предусмотрено ограничение 20 МБ, 3000 записей журнала, защита
  от некорректных ссылок результатов/дубликатов, попытка отката
  при ошибке локального хранения.
- Статистические плитки в правой панели: число учеников, проверок,
  средний результат и количество проверенных учеников.
- Всё работает локально: ни имена, ни ссылки из QBOOK не отправляются
  в GitHub. Тесты используют исключительно синтетические данные.

**Не включено в .qteacher:** сами QDIAG/QTPL документы, изображения
из IndexedDB и библиотека вопросов. Их переносимые архивы сохраняются
отдельно через соответствующие редакторы. Не выдавать .qteacher
за полный архив абсолютно всех данных Office.
