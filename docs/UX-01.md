# UX-01 — рабочее пространство преподавателя

Редактор конструктора и редактор банка используют общие поля, вкладки, форматирование, вставку MathML и научные инструменты. В банке сохранение остаётся явным и проверяет ревизию записи. В конструкторе изменения относятся к черновику QWORK. При открытии банка из конструктора исходное задание копируется в работу через существующий сценарий добавления.

Конструктор открывает сохранённый черновик или пустой экран с командами создания, импорта QWORK и подбора из банка. Демонстрация открывается отдельной командой. Недавняя работа доступна в текущем сеансе после открытия или создания нового документа поверх предыдущего.

Рабочая поверхность и панель команд описаны в [дизайн-системе](DESIGN_SYSTEM.md). «Предпросмотр» в редакторе задания банка использует печатную раскладку отдельного задания. Конструктор открывает печатную раскладку всей работы, а «Лист задания» показывает выбранное задание. Настройки рисунков и таблиц доступны в правой панели.

Проверки запускаются командами npm test, npm run build и node tests/ux01_browser.cjs. Сценарий работает на одноразовом профиле Chromium. Полноразмерные снимки и диагностические координаты находятся в evidence/ux-01. В Chromium проверяются 1366×768, 1920×1080, 2560×1440 и 3440×1440, масштаб устройства 125% и 150%, а также фрагменты панелей при 200%. Системное масштабирование Windows и интерактивный запуск WebView2 остаются открытыми.
