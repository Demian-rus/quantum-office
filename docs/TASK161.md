# TASK161 — редактируемые механические и электрические схемы

## Архитектура

База: Draft PR #147; ветка `feat/task161-physics-circuit-diagrams`, Draft PR #148.

- `src/core/work-physics.js` содержит единую векторную геометрию примитивов и точки подключения проводов.
- `src/core/work-model.js` расширяет QWORK v1 необязательными типами объектов и хранит ссылки проводов на `{id, port}`.
- `qwResolveDiagram` пересчитывает концы привязанных проводов после перемещения или поворота компонентов. Предпросмотр и печать используют общую модель и общий SVG.
- `src/core/work-geometry.js` обеспечивает выделение и перетаскивание компонент, включая ортогональные проводники.
- `src/core/work-builder.js` добавляет компактные палитры «Геометрия», «Механика», «Электричество», редактирование параметров, дублирование, Undo/Redo, поворот, изменение подписей и стилей.
- `scripts/build.mjs` включает модули в автономный HTML без внешних ресурсов.

### Доступные типы

**Механика**: `forceVector`, `velocityVector`, `accelerationVector`, `torque`, `dynamometer`, `weightSet` (6).

**Электричество**: `resistor`, `rheostat`, `cell`, `battery`, `lamp`, `switchOpen`, `switchClosed`, `ammeter`, `voltmeter`, `wireOrth`, `junction` (11).

Существующие линии, фигуры, блоки, нити, наклонные плоскости остаются доступны.

### Ограничения

- **Редактор схем, не симулятор цепей**: электрические потенциалы и токи не вычисляются.
- Провода хранят ссылки на контакты компонентов, но автоматический выбор обхода перекрёстков и топологический анализ электрических узлов не реализованы.
- Соединённые провода сохраняют ортогональность при перемещении и вращении компонентов; неподключённые могут редактироваться отдельно.
- При удалении компонента связь отсоединяется, чтобы старый QWORK продолжал открываться, геометрия остаётся видимой.
- QWORK v1 переносит все новые типы без принудительной миграции старых файлов.
- Встроенные нативные редактируемые таблицы вне области TASK161.
