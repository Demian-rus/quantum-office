## Исправления

- Исправлена незакрытая кавычка `id` в поле цвета объекта Studio. Выбор цвета снова меняет выбранный объект.
- Добавление текста, фигуры и фото теперь заменяет прежнее выделение; ранее мог оставаться выбран предыдущий слой.
- Заблокированный объект защищён от числового изменения через инспектор.
- Простой щелчок больше не заменяет canvas в DOM: работает настоящий двойной щелчок для редактирования текста.
- Прерванное перетаскивание возвращает геометрию и сохраняет прежний Redo; pointercancel, Escape и потеря фокуса обрабатываются.
- Скрытие боковых панелей больше не перемещает холст в колонку нулевой ширины. Инспектор доступен и на ширине 768 px.
- В общей шапке название документа не скрывается на 768/1024 px и не перекрывает навигацию. Геометрия одинакова для четырёх редакторов.
- Из контекстного меню ячеек были потеряны команды высоты строки и ширины столбца. Они восстановлены.
- QSLIDES восстанавливает активный слайд и выделенный объект вместо безусловного перехода на первый слайд.
- Общая кнопка «Сохранить» сохраняет QSTUDIO в Studio и QDOC в Writer. Экспорты PNG/HTML/TXT остаются отдельными командами.
- Экспорт PNG ожидает декодирования изображений. Состояние «Без коррекции» и маркеры выделения в файл не попадают.
- Превышение доступного места для черновика больше не скрывается: Studio предлагает скачать QSTUDIO. Ограничение TASK 094, молча пропускавшее автосохранение проектов больше 2 МБ, снято.
- `npm run dev` собирает и открывает актуальный `dist/index.html`, вместо старого корневого `index.html`.

## Работающие функции TASK 095

### Оформление

Кнопка в общей шапке открывает меню с миниатюрами: светлая, тёмная и системная темы. Выбранный вариант отмечен; выбор сохраняется. Системный вариант реагирует на изменение ОС. Меню закрывается по выбору, клику снаружи и Escape; клавиатурный фокус удерживается внутри открытого меню.

Акценты: зелёный, синий, фиолетовый, янтарный. Централизованы токены поверхностей, текста, границ, акцента, наведения, тени, скругления и высоты контролов. Цвета содержимого документов и canvas от темы не меняются.

### Studio

- Восемь разделов слева: шаблоны, элементы, текст, загрузки, фото, рисование, слои, настройки.
- Обе боковые панели сворачиваются. На узких экранах открываются поверх рабочей области.
- Четыре рабочих угловых маркера; фотографии сохраняют пропорции, Alt разрешает свободный размер; Shift сохраняет пропорции фигур.
- Поворот за круглый маркер с показом угла; Shift задаёт шаг 15°.
- Перемещение группы целиком, множественное выделение, группировка, дублирование, удаление, блокировка, видимость и порядок слоёв.
- Привязки к краям/центрам объектов и страницы с направляющими; Alt временно отключает привязку.
- Перемещение рабочей области инструментом руки, средней кнопкой или Space + перетаскивание.
- Двойной щелчок по тексту открывает редактирование на холсте. Ctrl+Enter применяет, Escape отменяет. Поддерживаются строки, шрифт, размер, цвет, жирность, межбуквенный интервал и выравнивание. Размер рамки измеряется canvas, а не оценкой числа букв.
- Добавлен треугольник; сохранены кисть, линия, прямоугольник и эллипс. Дополнены форматы обложки видео и баннера.

### Фотослои

Каждая загруженная фотография — самостоятельный слой с собственным исходником. Отдельно сохраняются яркость, контраст, насыщенность, экспозиция, размытие, фильтр и его интенсивность. Фильтры: оригинал, монохром, сепия, насыщенный. Есть отражение по двум осям и сравнение без коррекции.

Обрезка задаётся отступами от четырёх краёв исходника. Прямоугольник хранится отдельно от `src`; повторная обрезка и восстановление всего исходника не теряют пиксели. В этой версии обрезка числовая; перетаскиваемой рамки обрезки ещё нет.

Новые поля QSTUDIO являются необязательными расширениями версии 1. Проверены проекты, созданные настоящими TASK 093 и TASK 094. Проекты с новой коррекцией и обрезкой следует открывать в TASK 095: прежние сборки не отображают эти новые свойства.

## Как проверить вручную

Откройте `QuantumOffice_TASK095.html` в Chromium-браузере. Для разработки: `npm ci`, `npm test`, `npm run build`, `npm run dev`. Для специального сценария: `npx playwright install chromium`, `npm run test:studio`.

В Studio добавьте фотографию, откройте «Свойства», измените коррекцию и обрезку. Скачайте QSTUDIO общей кнопкой «Сохранить» и откройте его снова. PNG создаётся отдельной кнопкой. Явный файл QSTUDIO сохраняет исходники и все слои; черновик браузера ограничен доступной квотой.

## Ограничения и следующий этап

Не реализованы маски, ретушь, клонирование, кривые, выборочная коррекция светов/теней, температура, повышение резкости, градиенты/тени объектов и полноценная многостраничность Studio. Группы перемещаются и выравниваются вместе; общая рамка масштабирования/поворота нескольких объектов пока не добавлена. Импорт фото ограничен PNG/JPEG/WebP до 8 МБ на изображение; размеры страницы — 64–4096 px. Undo ограничен 35 состояниями. Это рабочая итерация, не готовый профессиональный фоторедактор или нативный установщик.

Для TASK 096 многостраничность следует вводить отдельной миграцией: документ v1 становится первой страницей, общие изображения сохраняются в таблице assets, страницы ссылаются на них по ID; порядок и активная страница отделены от данных слоёв. До реализации миграции и её тестов формат и работающий редактор v1 сохранены. Это проект следующего этапа, не уже работающая функция.

Windows/macOS installers, физическая печать и проверка браузера Opera на компьютере владельца в этой среде не выполнялись. Полная совместимость с любым XLSX не заявляется.
