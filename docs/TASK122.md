# TASK122 — Общие карточки учеников: таблицы ↔ диагностика

## Основание
Проверена структура присланного владельцем файла `График.qbook` локально
(личные данные не добавлялись в репозиторий): формат
`quantum-office-book-v1`, два листа, на листе **«Ученики» 11 имён
в A2:A12**; колонки A–F: Ученик, Ссылка, Информация, Родитель, Ссылка,
Информация. Гиперссылки находятся в `sheet.hyperlinks`.

## Первые общие функции платформы
- В таблице лист с заголовком A1 «Ученик» можно привязать одной кнопкой
  «Ученики» → «Связать текущий лист». Пользователь сам выбирает книгу
  и лист; приложение ничего автоматически не отправляет вовне.
- Источник читается из уже открытой книги в Quantum Office, а не из
  случайно найденных файлов. Список отражает изменения в таблице.
- На таблице доступна **карточка выбранного ученика**: информация,
  исходные ссылки, общая история диагностик, итоговые проценты,
  переход прямо к проведению.
- Возле имён, по которым есть результаты, появляется компактный
  индикатор «▣». Не меняет содержимое ячеек, формулы, оформление,
  исходные ссылки, объединения или QBOOK.
- В конструкторе/проведении открывается список учеников, связанный
  с таблицей; можно искать, выбирать или добавить всех одной командой.
  Не требуется каждый раз печатать имена вручную.
- При сохранении результата с уникальным именем из подключённой
  таблицы добавляется краткая запись в **единый локальный журнал**.
  Одна общая история для всех диагностик; не создаётся отдельная
  рабочая книга или лист на каждого ученика.
- В проведении доступна сворачиваемая общая история выбранного ученика.
- Для ранее проведённых диагностик есть кнопка «Связать прежние
  результаты» с подтверждением; повторный импорт одних и тех же
  записей предотвращается.
- Экспорт общего журнала и истории конкретного ученика — CSV,
  с защитой от формул в пользовательских строках.

## Безопасность привязки
- Связь хранит ID книги, ID листа, нормализованное имя; сортировка
  строк не привязывает результаты к другому человеку.
- Если есть два одинаковых имени, автоматическая привязка
  блокируется. Для таких случаев понадобится ручное присвоение
  уникального идентификатора ученика в следующем этапе.
- При повторном импорте одного и того же QBOOK создаётся новая
  книга с новым ID: её требуется подключить заново вручную.
- Ссылки на контакты открываются только по HTTP(S), в новой вкладке.
- Персональные записи остаются в браузере пользователя и его QBOOK;
  **не коммитятся в GitHub** и не отправляются в облако.
- Единый журнал пока хранится в localStorage **отдельно от QBOOK**.
  Скачанный исходный QBOOK не содержит журнал диагностик.
  Для резервной копии журнала есть явный CSV-экспорт.
  Не объявлять двустороннюю синхронизацию с файлом на диске.

## Предметы
Из встроенного списка убраны случайно добавленные русский язык,
биология, география и химия. Доступны **14 встроенных шаблонов по
физике, математике, информатике** (233 задания до дедупликации банка).
Личные шаблоны любых предметов не удалены и сохраняются.
