# TASK102 — Пошаговая диагностика в Quantum Writer

## Цель

Сделать проведение учебной диагностики таким же компактным, как интерактивные карточки в чате: **один вопрос, скрытый ответ, крупные оценки, видимый прогресс и мгновенный переход**. Сохранить все существующие задания, форматы и режим общего списка.

## Режимы

- **По одному** — режим по умолчанию для новых диагностик. Одновременно отображает только один вопрос, тему, номер из общего количества, процент оценённых и итоговые баллы за оценённые ответы.
- **Все вопросы** — прежняя прокручиваемая версия с полным набором карточек, итогами и журналом.
- Кнопки **Назад**, **Следующий**, **К непроверенному**, раскрываемая **Карта вопросов** с доступом к любому номеру.
- Ответ преподавателя скрыт до нажатия **Показать ответ**; при переходе на другую карточку показ сбрасывается.
- Три прежние оценки по-прежнему работают. При выборе новой оценки в пошаговом режиме интерфейс переходит к следующему вопросу (кроме последнего). При повторном выборе той же оценки она снимается.
- Автоматическая проверка числовых задач и тестов из TASK101 сохранена; после автооценки можно посмотреть результат и перейти дальше вручную.
- Для режима **По одному** сводная статистика и история доступны через сворачиваемый раздел **Подробные результаты и журнал**.
- Клавиши **1, 2, 3** — оценки; **←, →** — назад/вперёд; **R** — показать/скрыть ответ. Сочетания игнорируются при вводе в поля, селекты и редакторы.

## Совместимость

Состояние вида и текущего вопроса хранится в дополнительном поле display диагностического документа. Для старых QDOC/QDIAG поле необязательно: по умолчанию будет режим «По одному», старые оценки, записи журнала, ответы и обычный документ сохраняются. Полный список можно включить одним действием.

## Проверки

- tests/task102.test.js — нормализация состояния, ограничение индекса, выделение одной карточки, пустая диагностика и список.
- tests/task102_browser.cjs — сценарий пользователя: вопросы, ответы, оценка и автопереход, карта, клавиши, перезагрузка и экспорт.
- Актуализированы браузерные тесты TASK099–TASK101: старые предположения о наличии всех карточек теперь явно проверяют режим «Все вопросы».
- npm test, npm run build, GitHub Chromium smoke.

## Известные ограничения

Клавиатурные ускорители доступны только в режиме «По одному» и не затрагивают поля ввода. Данные учеников остаются локальными внутри документа; синхронизации между устройствами нет. Автопроверка свободных текстовых ответов не реализована.
