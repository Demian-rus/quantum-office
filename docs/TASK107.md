# TASK107 — Предпросмотр и сборка диагностик из библиотеки

## Цель

После TASK106 библиотека позволяла открывать готовые шаблоны, но это заменяло всю текущую диагностику. Теперь преподаватель может заранее прочитать вопросы и выбрать только нужные для урока, не теряя собранный материал.

## Новое в библиотеке

- Кнопка «Просмотреть» под каждым встроенным и собственным шаблоном открывает подробный просмотр с разделами, вопросами и скрытыми ответами.
- Каждый вопрос имеет флажок выбора. Можно выбрать все, снять выделение и просмотреть ответы без перехода к проведению.
- «Добавить выбранные в текущую» безопасно добавляет только отмеченные вопросы. Старые вопросы, имена учеников, активные оценки, результаты и текст Writer остаются на месте.
- Вопросы с идентичными формулировками (без учёта регистра и лишних пробелов) пропускаются. Если название раздела совпадает с существующим — вопросы добавляются туда; если нет — раздел создаётся. Номера идентификаторов назначаются заново.
- Перед действием показываются число добавляемых вопросов, новых разделов и пропущенных повторов.
- Лимиты 24 раздела и 240 вопросов проверяются **до изменения данных**: при превышении операция отклоняется целиком.
- При повторной вставке того же материала уже добавленные вопросы пропускаются.
- Для полного замещения документа прежняя команда «Открыть» сохранена с предупреждением о потере текущего набора и истории.

## Интерфейс

На больших экранах предпросмотр распределён по нескольким колонкам, на мобильных — по одной; каждый ответ раскрывается внутри своей карточки. Широкая область TASK106 и стиль оценивания «как в чате» сохраняются.
