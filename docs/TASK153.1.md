## Замечания владельца (19 ноября 2026)
1. Переменная `t` визуально тяжелее остальных; индекс `²` слишком близок.
2. Повтор названия, предметов и класса на второй странице.
3. «Ответ» под рисунком, хотя свободно место слева.
4. Неравномерная штриховка опоры и декоративный штрих внутри бруска.
5. Тонкий знак корня и тяжёлая черта; инородная форма латинской `c`.
6. Ручное создание ровных нитей с точными стыками и одинаковыми уровнями.
7. Опциональный дизайнерский QX справа сверху, без дублей и соцссылок.

## Реализация
- Только в режиме `booklet` повторяемая строка заголовка убрана, из первой шапки удалена вторичная строка предмета/класса, снизу остаётся только номер страницы.
- MathML получает единый стек совместимых математических шрифтов, принудительный normal weight без font synthesis и дополнительный отступ 0,09em перед верхними индексами. Тело QWORK/AST не изменяется; растризации формул нет.
- При правом рисунке `qwPreparePrintDocument` перемещает строку ответа в колонку условия, вниз к основанию рисунка с гарантией незалезания в текст; для остальных вариантов остаётся прежняя схема.
- SVG ground: шаг 14 единиц, одинаковые штрихи с полями по краям; SVG block: удалён декоративный штрих, сохранена геометрия и цвета; все экспорты используют эту же SVG модель.
- Инструмент rope в редакторе при включённой привязке выравнивается в вертикаль/горизонталь при погрешности не более 7 модельных единиц; ground и уже нарисованная rope имеют непрерывные проекционные якоря вместо привязки только к концам. Система натяжений не симулируется, связанная кинематика нитей не реализована.
- QX на каждой странице в верхнем правом углу: необязательные стили Academic Tech, Scientific, Minimal; кнопки выбора доступны только для booklet в PDF-предпросмотре; чёрно-белый флаг. По умолчанию бренд выключен. Метаданные QWORK и остальные редакторы не изменены.

## Контроль

- Полная существующая Chromium/verify матрица.

## Ограничения
- MathML использует встроенные математические шрифты платформы; на Windows/Chromium предпочтение Cambria Math, на Linux доступные совместимые fallback. Визуальная идентичность на всех системах не гарантирована; следует проверить PDF на Windows.
- Новая привязка нитей выравнивает ручное рисование и стыки, но не создаёт физически связанных соединений с автоматическим пересчётом при перемещении шкива/опоры. Это отдельная задача, а не заявленная реализация.
- Выгрузка выделяемого векторного PDF по-прежнему идёт через системный диалог печати.
- PDF-тема QX не утверждает официальную принадлежность ЕГЭ и не подменяет название авторской работы.
