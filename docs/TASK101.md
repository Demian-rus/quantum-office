# TASK101 — Автоматически проверяемые задания в Quantum Writer

## Реализовано

- Тип **«Выбор одного»**: 2–6 редактируемых вариантов, один правильный ответ.
- Тип **«Несколько ответов»**: 2–6 вариантов, можно отметить несколько правильных. Полный правильный набор даёт «Знает», непустое подмножество только правильных — «Частично», ответы с ошибочными вариантами — «Не знает».
- Тип **«Число»**: ожидаемое число и абсолютная погрешность; поддерживаются запятая и точка как десятичные разделители.
- Ответ учащегося сохраняется в активной сессии. Кнопка «Проверить автоматически» выставляет ту же оценку, что и преподаватель, поэтому веса заданий TASK100 и статистика продолжают работать.
- Ручные вопросы и задачи по-прежнему оцениваются преподавателем.
- Кнопка «+ Автоматические задания» добавляет демонстрационные задания по физике, не заменяя пользовательский материал.
- Отчёт HTML — отдельная печатная страница с итогом, количеством проверенных заданий и статистикой разделов. Можно сохранить в PDF через системную печать браузера.
- Для новых исторических записей фиксируется статистика разделов на момент проведения, чтобы редактирование вопросов не меняло прошлые проценты.

## Совместимость и ограничения

Сохраняются текущие форматы QDOC и QDIAG v1. Старые задания остаются ручными. Не требуется интернет. Отчёт может содержать имя ученика — храните его как персональный документ.

Не реализованы синхронизация между устройствами, импорт DOCX, глобальная база учеников и автоматическая проверка развёрнутых текстовых решений. Числовые ответы сравниваются по абсолютной, а не относительной погрешности.
