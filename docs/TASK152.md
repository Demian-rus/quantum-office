# TASK152.0 — геометрические инструменты редактора схем

Основа: `main` @ `710f6814bf5b3c4709fb047d55182b4d9ef0faf8`.
Ветка: `feat/task152-diagram-tools`. Этот этап ограничен геометрией.

## Что реализовано

- **Эллипс**: отдельный объект `ellipse`, две независимые полуоси, настройка границ, перемещение/поворот, цвет контура/заливки, толщина и подпись.
- **Правильный многоугольник**: `regularPolygon`, от 3 до 12 сторон, вершины вычисляются из окружности, вписанной в квадратную часть заданной рамки. Настройка количества сторон и координат/границ; перемещение, поворот, стиль, подпись.
- **Середина отрезка**: `point` с `construction: {kind: 'midpoint', reference: id}`. Следует за конечным отрезком, включая поворот.
- **Серединный перпендикуляр**: `infiniteLine` с `construction: {kind: 'perpendicularBisector', reference: id}`; проходит через середину конечного отрезка, обновляется при правках.
- **Биссектриса угла**: `ray` с `construction: {kind: 'angleBisector', reference: id}`; направлена по сумме нормированных направлений сторон, обновляется при правке угла.
- Вся геометрия использует существующий SVG и контур печати; отдельные картинки или элементы только в палитре не добавлены.
- Модель и QWORK остаются `quantum-work` v1; новые поля необязательны для старых документов.
- Исходный объект при удалении **не удаляет** автоматически зависимые: связь снимается, последнее вычисленное положение остаётся.

## Поведение и ограничения

- Зависимые построения нельзя свободно перетаскивать отдельно от исходной фигуры: так сохраняется математическая связь. Их подпись, цвет и стиль редактируются отдельно; сама геометрия перемещается при редактировании исходного объекта.
- Допустимые источники для середины и серединного перпендикуляра: конечные `line`, `dashed`, `arrow`, `dimension`, `doubleArrow`; для биссектрисы — `angle`.
- Изменение числа сторон многоугольника не превращает его в произвольный многоугольник. Вершины намеренно вычисляемые, не перетаскиваются по одной, чтобы сохранить равенство сторон.
- Полноценное масштабирование мышью за ручки пока отсутствует в базовом редакторе; размер новых фигур задаётся мышью при создании и затем через поля границ.
- Механика, электрические символы и узловые соединения проводников — **следующая отдельная партия**, не заявляются готовыми.

## Контроль

- `npm test`: в том числе `tests/task152.test.js` с QWORK, проверкой зависимостей, корректностью многоугольников и негативными случаями.
- `npm run build`: один автономный `Quantum-Office.html` и идентичный `dist/index.html`.
- `node tests/task152_browser.cjs`: автономный Chromium, создание и редактирование фигур, зависимые построения, Undo/Redo, QWORK сохранение/импорт, печатный SVG, PDF и узкая рабочая область.
- GitHub Actions: независимая задача `task152-diagrams` с артефактами `evidence/task152/`, плюс общие `verify`/`browser` регрессии.
- **До завершения CI** результаты проверок не считаются подтверждёнными. Запуск на Windows из браузера владельца также требует отдельного тестирования.

## Правила интеграции

Не изменять Writer, Sheets, Slides, диагностику, тему QX и PDF-layout ради TASK152. Merge в main — только по разрешению владельца.
