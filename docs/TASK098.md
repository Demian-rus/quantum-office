# TASK098 — текстовые блоки и работа с цветом

База: TASK097 `ff881a5dc36f04f7dd0cdd63b5fe961fcc79e02b`, Draft PR #83.
Ветка `feat/task098-studio-creative-tools`, отдельный зависимый Draft PR.
Слияния #81/#82/#83 и main не выполняются.

## Реализовано: P1 и P2

- Текст: шрифт, размер, жирность, курсив, подчёркивание, цвет, межбуквенный и
  межстрочный интервалы, три выравнивания; многострочная рамка с автоматическим
  переносом и изменением размеров мышью без изменения размера шрифта.
- Контур с цветом/толщиной; тень с цветом, смещением и размытием; цветная
  подложка и её прозрачность. Общая прозрачность текста действует на всё оформление.
- Общая геометрия для холста/выделения/PNG, кириллица, пустые строки,
  графемы и длинные слова. Явные запасные семейства шрифтов исправляют одинаковое
  отображение недоступных системных шрифтов. Шрифты не встраиваются в QSTUDIO.
- Пипетка: предварительный RGBA под курсором, правильные координаты при масштабе,
  композиция без маркеров; применение к тексту, векторной фигуре, кисти/новому
  объекту либо фону. Прозрачный пиксель явно переносит alpha 0.
- Палитра: готовые и собственный цвет, HEX, непрозрачность, 16 недавних RGBA-цветов.
  Цвета интерфейса используют прежние токены; цветные образцы — содержимое документа.
- Undo/Redo, совместимый QSTUDIO v1, новые ограничения и атомарное отклонение
  повреждённых новых полей. История недавних цветов — отдельная настройка браузера.

## Частично / отложено

P3 получил непрозрачность новых штрихов через палитру, но жёсткость, мягкая
кисть, сглаживание и настоящий ластик не реализованы. P4 новые фигуры/стили,
P5 JPEG/WebP/параметры экспорта и P6 дополнительные удобства отложены.
Кнопок-заглушек этих инструментов нет. Следующий приоритет — безопасная модель
неразрушающей растровой маски со сбросом, ограничением памяти и одним Undo на жест;
затем мягкая кисть/ластик, фигуры и экспорт. Старые инструменты и PNG сохранены.

Текст форматируется целым объектом, без разных стилей внутри одной строки.
Высота рамки растёт по содержимому; это не фиксированная область с обрезанием
текста. Контур/тень не входят в рамку выделения. Разные ОС могут дать разные
метрики системных шрифтов. Пипетка переносит общую непрозрачность объекта,
а не отдельную альфу его заливки. Родные установщики здесь не проверяются.

## Проверки и исправления

Новый набор проверяет реальные поля/мышь, переносы, 17 настроек оформления по
пикселям, размер и цвет, Undo/Redo, отмену с непустым Redo, QSTUDIO/PNG,
RGBA-пипетку, текст/фигуру/кисть/фон, недавние цвета, повреждённые поля и все
реальные проекты TASK093–097. При просмотре проверяется светлая и тёмная темы.
Набор включён в Chromium CI; результаты и точный финальный SHA передаются
с готовыми HTML/ZIP. Минимальные команды: `npm test`, `npm run build`,
`npm run test:creative-tools`, существующие TASK095–097 и исторические сценарии.

Полное описание полей: [QSTUDIO.md](QSTUDIO.md). Структура CSS TASK096 сохранена;
новая геометрия контролов только в studio.css, без цветовых исключений тем.
