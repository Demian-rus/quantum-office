# QSTUDIO: совместимость TASK097

Формат остаётся JSON, `version: 1`. TASK097 читает проекты TASK093–095;
отсутствующие поля не дописываются при открытии. Оригинальные `src` и `imageSrc`
остаются встроенными PNG/JPEG/WebP data URL. Исходные пиксели не перезаписываются.

## Новые необязательные поля

| Поле объекта | Значения / значение при отсутствии |
| --- | --- |
| `name` | Непустое название до 120 символов; иначе название типа |
| `mask` | `none`, `rect`, `round`, `circle`, `ellipse`; по умолчанию `none` |
| `roundness` | 0–0.5 от меньшей стороны рамки; по умолчанию 0.15 |
| `frame` | `{zoom: 1…10, panX: -1…1, panY: -1…1}`; без поля `{zoom:1,panX:0,panY:0}` |
| `adjust.temperature`, `adjust.tint` | −100…100; по умолчанию 0 |
| `adjust.highlights`, `adjust.shadows` | −100…100; по умолчанию 0 |
| `adjust.gamma` | 0.2…3; по умолчанию 1 |
| `adjust.sharpness`, `adjust.vignette` | 0…100; по умолчанию 0 |

`name` относится ко всем слоям; маска и `frame` применяются к изображениям.
Поля TASK095 (`crop`, коррекция, отражения, поворот, `groupId`, `opacity`,
координаты) сохраняют смысл. Массив `strokes` упорядочен от заднего слоя к переднему.
Группы остаются плоскими связями `groupId`. Прозрачность группы устанавливается
у незаблокированных участников, без отдельного композиционного буфера.

## Геометрия и история

`crop` — нормализованная область оригинала `{x,y,w,h}`. Минимальные ширина и
высота — 5% оригинала. `frame` выбирает увеличенную подобласть внутри `crop`,
сохраняя пропорции; эффективный zoom также ограничен этими 5%.
Сдвиг −1/+1 достигает края доступной области. Маска ограничивает отрисовку,
а не оригинал. Круг имеет диаметр меньшей стороны объекта; эллипс занимает всю рамку.

Визуальная обрезка начинается с текущей видимой подобласти, учитывает отражения
и поворот. До «Применить» документ и история не меняются. Изменённое применение
переносит область в `crop`, удаляет поглощённое `frame`, обновляет размер/позицию
объекта, сохраняя положение на холсте. Отмена и применение без изменений
сохраняют прежние поля и Redo. Числовая обрезка сбрасывает положение фото;
«Весь исходник» восстанавливает полную область. Маску и коррекцию можно снять отдельно.
Завершённые перетаскивания обрезки, фото в рамке и слоёв создают одно действие Undo.

## Обработка и экспорт

Общий рендерер рисует холст и PNG. Новые коррекции обрабатывают RGBA выбранного
изображения: относительный баланс RGB; взвешенные по яркости тени и света;
гамма `pow(v,1/gamma)`; радиальное затемнение; четырёхсоседнее повышение резкости.
Альфа сохраняется. Температура не является шкалой Кельвина. После новых операций
применяются прежние Canvas-фильтры TASK095, трансформации, маска и прозрачность.
Нейтральные новые параметры используют прежний путь рендеринга.

Это sRGB-байты, без RAW/ICC/HDR. Буфер ограничен длинной стороной 4096 px,
максимум 16 777 216 пикселей. Кэш ограничен шестью результатами и 20 млн пикселей.
Большие фотографии могут обрабатываться медленно; Web Worker/GPU пока нет.
PNG ждёт загрузки фотографий, сохраняет обработку даже при «До / После»,
исключает неприменённый crop-предпросмотр, маркеры, сетку и направляющие.

## Проверка и совместимость

Холст: 64–4096 px по каждой стороне; до 5000 объектов и 300 000 точек.
Проект: до 32 МБ; отдельный импорт фотографии: до 8 МБ. Импорт сначала проверяет
JSON, геометрию, новые диапазоны и декодирование всех фотографий, затем заменяет
документ. При ошибке документ, Undo и Redo сохраняются. Экспорт проекта проверяет
модель. Неизвестные совместимые JSON-поля сохраняются; старые версии приложения
не обязаны исполнять новые свойства.

Legacy-фикстуры TASK093/094 и TASK095 открываются без изменения свойств.
Последняя снята реальным экспортом движка TASK095 из сборки TASK096 до изменений
TASK097; содержит фото, crop, фильтр, отражение, поворот, группу и кириллицу.
Новый Chromium-набор проверяет поля, историю, пиксели, реальные скачивания,
повторное открытие и атомарное отклонение повреждённых файлов.
Автопроект браузера временный; для переноса нужен явный файл QSTUDIO.
