# TASK119 — Исправление компактных карточек, сохранение шаблона из конструктора и расширение правой панели

## Исправления компоновки
- Компактные карточки вопросов всегда ограничены шириной своего раздела.
- Карточка с длинным вопросом не сдвигает вправо кнопки, список типов или сам раздел.
- При недостаточной ширине строка инструментов переносится на отдельную строку **внутри** карточки; горизонтальной прокрутки карточек не появляется.
- Вопросы любого размера обрезаются только в *предпросмотре компактной карточки* многоточием; полный текст виден при раскрытии «Редактировать».
- Правая панель диагностики расширена примерно до 290–355 px (в зависимости от экрана); центральная область занимает оставшуюся ширину без фиксированного островка.
- Для экранов менее 1330 px сохраняется двухколоночная компоновка, менее 900 px — одна колонка.

## Сохранение своих шаблонов
В конце **Конструктора** перед переходом к проведению расположен блок «Сохранить изменения в шаблон»:
- Поля «Предмет», «Класс», «Цель» и «Мой шаблон для обновления».
- «Сохранить как новый шаблон» создаёт собственную копию исправленной диагностики.
- «Обновить мой шаблон» перезаписывает только явно выбранный *собственный* шаблон **после подтверждения**.
- «Скачать библиотеку .qtpl» выгружает переносимый файл со всеми пользовательскими шаблонами.
- Встроенные материалы остаются неизменяемыми, независимо от изменений в редакторе.
- В шаблоны не входят ученики, история, оценки, сессии.
- Совпадающее имя своего шаблона не вызывает скрытого перезаписывания: пользователь должен выбрать «Обновить».
- Библиотека сохраняется локально на устройстве, поэтому для устойчивого хранения и переноса необходим отдельный экспорт .qtpl.

## Проверка
- `tests/task119.test.js`: создание из встроенного шаблона, редактирование и обновление своего, сохранность исходного, защита от дублирования и некорректного ID, отсутствие персональных данных в шаблоне.
- `tests/task119_browser.cjs`: измерение **каждой** компактной карточки на 2048, 1600, 1440, 1280, 1100, 900, 650 и 390 px; корректная ширина правой панели; редактирование вопроса, сохранение нового шаблона, обновление, .qtpl и перезагрузка.
- `npm test`, `npm run build` и полная браузерная матрица.
- Ранее согласованные интерфейсы вкладок, редактора текста, таблиц, презентаций и диагностики не меняются.
