# TASK154 — единая типографика PDF, редактор печатного заголовка и банк вариантов

Base: PR #142 / commit 0cfe50e1edfcf09dbb4d9421ab12c337942ae2dc. Draft PR в ветку fix/task1531-print-math-diagrams. Main не изменять, merge только с разрешения владельца.

## Цель по замечаниям владельца от 2026-11-19
* У всех форматов экспорта PDF должна быть единая книжная типографика, один MathML-стек, управляемые шрифт и цвет.
* В окне макета отдельная панель печатного оформления: включение заголовка, собственный текст независимо от имени проекта, шрифт, кегль, выравнивание, цвет; текст заданий, поле с рисунками, предмет/класс, вариант, номера страниц и QX.
* «Новая работа» не должна появляться в PDF у нового документа, если заголовок не задан и не включён.
* Удалить служебные предупреждения о будущих ОГЭ/ЕГЭ-шаблонах.
* Подготовить ручную сборку аналога ЕГЭ-2018 и других вариантов из банка заданий с фильтрами по году, предмету, классу, экзамену, части, номеру и сложности.

## Реализация
1. QWORK v1 продолжает использовать прежние три обязательных печатных поля: fontPt, figurePosition, topicHeadings. Все новые поля опциональны: showTitle, titleText, titleFont, titlePt, titleColor, titleAlign, bodyFont, bodyColor, showMeta, showVariant, showPageNumbers, theme, monochrome. Значения ограничены whitelist/range. Существующие проекты с незаданными новыми полями совместимы.
2. Печатный заголовок не меняет название QWORK проекта. Пользователь может отключить печать заголовка или указать собственный текст. Новая работа без явно заданного заголовка не печатает «Новая работа».
3. Все четыре режима (Экзаменационный сборник, Компактный сборник, Лист для решения, Обычная контрольная) получают унифицированный font stack и MathML. Управление оформлением расположено в боковой панели PDF-предпросмотра; адаптивно переносится сверху на узком окне.
4. QX theme теперь сохраняется в QWORK, а не теряется при закрытии предпросмотра. Векторный бренд остаётся необязательным.
5. QWBANK v1: новые необязательные поля year, part, slot, difficulty при сохранении собственной задачи. Старые .qwbank сохраняют работоспособность. При импорте проверка метаданных, ограничения 500 записей и запрет переполнения.
6. Банк: поиск, фильтры, выбор конкретных вопросов чекбоксами, сохранение порядка выбора, кнопка «Собрать вариант → PDF». Новая работа создаётся из глубоких копий задач, получает уникальные IDs и bank source IDs, открывается в PDF-макете. Действующие задания перед заменой не удаляются без подтверждения. Нажать «Скачать PDF» после просмотра.
7. Банк заданий пока локальный (localStorage), есть ручной импорт/экспорт QWBANK. В интерфейсе не обещается удалённая синхронизация.

## Ограничения
* В новой итерации нет автоматического подбора заданий по уровню или распределения по темам. Пользователь выбирает вручную; порядок — порядок кликов.
* Сборка создаёт PDF макет, а не обход браузерного системного диалога. При печати нажать «Сохранить как PDF», текст остаётся выделяемым, собственная SVG-графика — векторной.
* Импорт сканов ФИПИ или внешнего банка автоматически не реализован.
* Нумерация в каталоге «номер задания» — метаданные; в печатном варианте задачи нумеруются по порядку отбора.
