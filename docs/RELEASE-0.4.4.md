# Quantum Office 0.4.4 — Windows x64

База: принятый BANK-03.1 9112142ff6f68a89a3a37013cf79adf27ffd5e23; включает EXAM-01 (#162) и BANK-03.1 (#163). Все функции 0.4.3 сохранены; новые функции не добавляются. Вариант N, нумерация, постоянные номера, пагинация решений, исправления свойств и Undo/Redo схем, годы актуальности, массовые операции, фильтр и защита сборки, переносимые QWBANK.

NSIS currentUser, Tauri 2, Windows x64 MSVC, WebView2 offlineInstaller. Идентификатор com.quantumoffice.desktop, SQLite schema 1 и штатные пути неизменны. HTML IndexedDB v3 с индексом examYears. Установщик не подписан.

## Безопасное обновление
В 0.4.3 экспортировать проверенную резервную копию банка/Office, сохранить важные QWORK/QBOOK и другие документы. Закрыть все окна Quantum Office, убедиться, что процесс завершился; скопировать целиком %APPDATA%\com.quantumoffice.desktop и, при наличии, %LOCALAPPDATA%\com.quantumoffice.desktop в отдельное безопасное место. Не копировать открытые SQLite-файлы. Проверить SHA-256 EXE по manifest.json / SHA256SUMS.txt. Запустить NSIS 0.4.4 поверх существующей установки в том же каталоге, не удалять данные и не менять профиль Windows. После запуска открыть «О программе», проверить 0.4.4, банк, номера, изображения, черновики и настройки. При ошибке прекратить запись и сохранить обе копии; не восстанавливать архив поверх рабочего банка без проверки.

## Проверки
GitHub Actions строит все артефакты из одного HEAD. Отдельно строит исходную 0.4.3 из f2d1432c3134b605a549c91acd4950ef959a7f36 и проверяет обновление в одноразовом Windows-профиле. Результаты — только в фактических логах и evidence; ручная приёмка владельцем не подменяется CI. BANK-03.2 не начат.

## Исправление при приёмке
Первый настоящий Windows-прогон выявил отсутствие `QW_EDUCATION_TEXT_CSS` в standalone native print.js после удаления ESM-импортов. Сборка ресурса теперь использует те же три функции раскладки, что браузерный PDF-предпросмотр; добавлена проверка исполнения классического скрипта и реального окна предпросмотра в установленном приложении. Первый установщик от 6e4cb3b не использовать; требуется новый артефакт с итогового HEAD.
