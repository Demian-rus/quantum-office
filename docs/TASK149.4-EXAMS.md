# Следующий этап — официальные экзаменационные шаблоны

Статус: **не реализовано**. TASK149.4 разрешает завершить основные форматы
и вынести полноценные ОГЭ/ЕГЭ в самостоятельную разработку.

В новом выборе формата экзаменационный пункт недоступен. Старые `layout: exam`
открываются как прежний компактный макет; они не подтверждают соответствие
официальному экзамену. Демонстрационный экзаменационный PDF сейчас не создаётся.

Для каждого поддерживаемого сочетания нужны отдельные данные шаблона:

- Экзамен, предмет/уровень и год выбираются явно. ОГЭ по математике,
  ЕГЭ по профильной математике и ЕГЭ по физике проверяются независимо.
- До реализации скачать официальные демоверсию и спецификацию ФИПИ выбранного
  года; записать точные URL, дату проверки и контрольные суммы файлов.
  Пока документы не проверены, экспорт не должен заявлять соответствие.
- Зафиксировать структуру частей, номера и типы заданий/ответов, инструкции,
  места для развёрнутых решений, таблицы и обязательные разрывы страниц.
  Сверка должна опираться на конкретные страницы официальных документов.
- Размещать авторские задачи пользователя; не переносить официальные условия
  в демонстрационные фикстуры. Не обещать официальные оценочные критерии без
  отдельной проверки соответствующего документа.
- Использовать общие математический/SVG-рендереры, измерения и пагинатор.
  Шаблон задаёт структуру/геометрию, а не новый PDF-движок.
- Добавлять только необязательную проверяемую метаинформацию QWORK. Старые
  контрольные, сборники, листы для решения и данные ответов сохранять без миграции
  содержимого. Повреждённые настройки отклонять атомарно.
- Приёмка: авторский полный вариант каждого сочетания, структурная сверка,
  QWORK round-trip/коррупция, отдельный ключ, фактическое число страниц PDF,
  все страницы отрисованы и визуально сравнены с проверенной демоверсией.

Готовность одного сочетания экзамен/предмет/год не распространяется автоматически
на остальные. Сначала реализовать и доказать один полностью сверенный шаблон.
