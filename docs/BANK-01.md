# BANK-01 — рабочее пространство банка заданий

База `8d9f57354fa2d5d319482c67371026a07dcf0034`, локальная ветка `feat/bank-01-workspace`. Этап подготовлен к пользовательской приёмке.

## Что изменилось

- Слева — раскрываемый список предметов, классы, экзамены, темы, подтемы и дополнительные фильтры. «Все задания» сбрасывает поиск и фильтры. Разделы представлены уже существующим полем темы.
- В центре — постоянные номера, короткие условия, метаданные, выбор строки и флажки подбора. «Добавить выбранные» и «Собрать вариант → PDF» находятся над каталогом. Файловые операции собраны в меню «Файлы и данные».
- Справа — полное условие, ответ, раскрываемое решение, критерии, редактирование, добавление и удаление. Увеличенный просмотр скрывает панели банка, оставляет решение доступным и закрывается по Esc.
- Настройки ширины, сворачивания и сброса используют механизм панелей TASK167.3. После редактирования каталог восстанавливает фильтры, запрос, страницу и позицию прокрутки. Если выбранное задание исчезло из результатов, открывается первая строка текущей страницы.
- Поиск ждёт 180 мс после последнего ввода. Смена запроса инвалидирует предыдущие чтения списка и карточки. Ошибка чтения снимает индикатор загрузки и очищает устаревшую выдачу. Личные вопросы из диагностики обрабатываются с текущим поисковым запросом.

## Хранение

IndexedDB сортирует найденные записи по постоянному номеру перед пагинацией, как SQLite. Для выдачи без фильтров IndexedDB использует счётчик индекса номера и читает только нужную страницу. Поиск по категории хранит вне страницы только номера и ID совпадений. Каталог запрашивает записи без изображений, полная карточка читается по ID. Сохраняются действующие схемы SQLite и IndexedDB, ревизии, форматы QWORK/QWBANK и печатный рендерер.

## Предварительный просмотр в отдельном профиле

В PowerShell из корня рабочей копии откройте свежий автономный `Quantum-Office.html` в отдельном профиле Microsoft Edge.

```powershell
$previewProfile = Join-Path $env:TEMP "QuantumOffice-BANK01-$([guid]::NewGuid())"
$previewHtml = (Resolve-Path -LiteralPath '.\Quantum-Office.html').Path
$previewEdge = Join-Path ${env:ProgramFiles(x86)} 'Microsoft\Edge\Application\msedge.exe'
& $previewEdge "--user-data-dir=$previewProfile" --no-first-run $previewHtml
```

Новый профиль открывает пустой банк. Для приёмки используйте «Файлы и данные → Импорт QWBANK» и файл `evidence/bank-01/fixture.qwbank`. Под № 00002 находится задание с формулой, графиком и раскрываемым решением.
