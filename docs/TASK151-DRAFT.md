# Проект TASK151 — внедрение утверждённой темы Квант Икс | QX

**Статус:** проект задания, не разрешение на реализацию или merge.
**Репозиторий:** Demian-rus/quantum-office.
**База:** точный принятый HEAD TASK150 после решения владельца; при старте
сверить main/PR/CI и вписать полный SHA. Не использовать устаревший SHA.
**Ветка:** feat/task151-qx-export-theme. Draft PR, merge только владельцем.

## До реализации

Владелец выбирает A Academic Tech, B Scientific или C Minimal и утверждает
знак, цвет, шрифты и поведение monochrome. Определить режим включения темы
(явная настройка экспорта/профиля), текст метаданных и допустимый fallback
для конфликтующих пользовательских колонтитулов и заполненных слайдов.

## Объём

1. Прочитать AGENTS, PROJECT_CONTEXT, TASK150 и инвентаризацию экспортов.
2. Создать общий registry темы с version/capabilities и отдельным хранением
   настроек экспорта. Не менять схемы документов без отдельного согласования.
3. Подключить адаптер конструктора к обычному preview/Print-to-PDF; показать
   выключенный/включённый бренд, цветной/монохромный preview. Тот же renderer
   должен использоваться для ученика и отдельного ключа.
4. Writer: HTML/PDF и отдельный DOCX-adapter; документ/его локальные стили
   сохранять. Не дублировать существующие колонтитулы и не закрывать текст.
5. Sheets: print/PDF и поддержанные OOXML print/properties для XLSX;
   значения, формулы, размеры, графики и стили клеток не переписывать.
6. Slides: overlay только при экспорте PNG с проверкой коллизий. Не создавать
   PPTX/PDF как скрытый побочный функционал этой задачи.
7. Для TXT/CSV/родных JSON/ZIP использовать capability map: filename или
   отдельный manifest по явному выбору. Не добавлять бренд в содержимое.
8. Метаданные PDF/OOXML/HTML задавать только поддержанным способом. Не
   использовать branding для выдуманных утверждений о подлинности/авторстве.

## Доказательства

- npm test/build; все TASK149.3–150, Writer/DOCX, Sheets/XLSX и Slides/PNG.
- Полная CI-матрица один раз после адресных проверок.
- Снимок документа до/после каждого экспорта идентичен, включая ID/ответы.
- QWORK/QDOC/QBOOK/QSLIDES round-trip и повреждённый импорт атомарны.
- PDF — выделяемый текст, формулы/векторы, без утечки ответов; все страницы
  render-and-review, проверка границ/заполненности/номеров/переносов.
- Эквивалентность preview/PDF; unchanged строгая проверка AB 0,3pt.
- Одинаковые материалы в color/BW, корректные метаданные без учебных данных.
- Offline HTML, шрифты без сети, CRC ZIP и воспроизводимость сборки.
- Нативная Windows + Linux проверка реальных PDF. Если Windows недоступен,
  явно оставить это ограничением, не объявлять межплатформенную приёмку.

Потеря данных, несовместимая миграция, скрытая модификация текста/формул,
утечка ответов, необходимость нового формата или широкого рефакторинга.
