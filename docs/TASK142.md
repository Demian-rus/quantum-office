# TASK142 — DOCX и рабочее место диагностики

База: TASK141 / PR #126, `b0dc84abc2c269f1dab028e119f2df640b52db26`.
Ветка: `feat/task142-diagnostics-workbench-docx`. Один Draft PR в ветку
TASK141, без изменения main и объединения предыдущей цепочки.

## Исправление TASK132

Первопричина подтверждена в Chromium на исходной сборке TASK141:
Playwright `download.path()` возвращал файл с именем GUID без расширения.
Импортёр выбирает формат по имени/MIME. Тест передавал этот временный путь
в input вместо скачанного `Новый документ.docx`, поэтому ZIP попадал в
текстовую ветку импорта: документ начинался с `PK`, заголовка H1 не было.
DOM-селектор `#qo-writer-page h1` правильный, увеличение таймаута не нужно.

Тест сохраняет загрузку через `download.saveAs()` с её настоящим именем,
создаёт **новый пустой документ** перед импортом и ждёт реального заголовка,
а не фиксированную задержку. Существующие проверки сохранены; добавлены
проверки жирного и курсива после обратного импорта. TASK132 проходит:
заголовок, оформление, списки, таблица, ссылка, параметры страницы,
колонтитулы, экспорт и повторный импорт, экран телефона.

Приложение также больше не читает неизвестный файл или ZIP/NUL-поток как
TXT. Ошибка оставляет открытый документ неизменным; input очищается,
чтобы тот же исправленный файл можно было выбрать повторно. DOCX
поддерживает распознавание по корректному MIME, кроме расширения.

## Исправленные проблемы интерфейса

- Был только список разделов: теперь он содержит отдельные вопросы с
  номерами, выделением выбранного и переходом к редактированию.
- Параметры терялись под длинными карточками: выбранный вопрос может
  вынести тип, баллы, частичный зачёт, раздел, критерии и подсказку в
  компактный инспектор. **Перемещаются настоящие контролы**, дубликатов
  редактирования нет. Можно вернуть параметры в карточку.
- Панели забирали пространство: их можно скрыть; на небольшом экране
  инспектор работает как закрываемая панель, список разделов свёрнут.
- Пустые блоки картинок занимали сотни пикселей: они свёрнуты в короткие
  строки. Добавление файла, вставка скриншота и рисование сохранены.
- На каждой библиотечной карточке было до семи кнопок: оставлены
  редактирование/открытие и просмотр, остальные операции — в меню.
  Структура разделов открывается по запросу, есть счётчик результатов.
- Поиск находил только метаданные: теперь ищет также по тексту вопросов,
  ответов и названиям разделов. Пустой результат предлагает сброс фильтров.
- Повреждённая личная библиотека могла быть частично прочитана и затем
  перезаписана: запись блокируется, есть предупреждение и выгрузка
  исходных данных для восстановления.
- Точный балл пересоздавал поля и съедал следующий клик: теперь
  обновляются показатели и отметки без замены полей, Save и навигации.
  Проверены переход в комментарий и немедленное сохранение после балла.
- Настройки диагностики при проведении можно свернуть; исходный снимок,
  ответы, оценки, комментарии, история и привязка к ученикам сохранены.

## Полезные действия

В конструкторе: `Ctrl+S` — сохранить, `Ctrl+Enter` — новый вопрос,
`Alt+↑/↓` — переместить выбранный вопрос, `Ctrl+D` вне текстового поля —
дублировать. Контекстное меню мышью или `Shift+F10` действует на реальные
вопросы/разделы; удаление заполненного вопроса подтверждается.

Добавлена необязательная подсказка ученику. Она переносится в снимок,
шаблон и банк и видна при проведении только по отдельной кнопке. Ответ
преподавателя по-прежнему скрыт. Статус сохранённого TASK141 переносится
в новую схему подписи без ложного предупреждения об изменениях.

## Совместимость и пределы

Расширение QDIAG version 1 — необязательное поле `question.hint`.
QDIAG/QDIAGX/QDOC, QTPL/QTPLX и QBANK/QBANKX сохраняют его обычным путём.
Настройки панелей вынесены в отдельный локальный ключ, не в задания.
QBOOK, движки Таблиц, Презентаций и Студии не переписаны.

Сохраняются ограничения TASK141: локальное хранение с обязательным явным
экспортом для переноса/резервной копии, один незавершённый снимок на
документ, 30 шаблонов, 24 раздела/240 вопросов, 80 локальных учеников,
50 записей истории. Формулы — символы и индексы, без LaTeX. DOCX —
ограниченная совместимость, не полная поддержка сложной вёрстки Word.
Работа на настоящем Android/iOS, Firefox/Safari и нативные установщики
этой задачей не подтверждались.

## Проверки и доказательства

`tests/task142.test.js` — четыре проверки переноса подсказок, полнотекстового
поиска, миграции сохранённой подписи и защиты повреждённой библиотеки.
`tests/task142_browser.cjs` — создание с нуля, инспектор без дублей,
горячие клавиши/меню, поиск, независимый снимок, оценка и фокус, немедленное
сохранение, восстановление, защита импорта. Метрики 18 компоновок:
1440/768/390 CSS px и эквиваленты zoom 125/150/200% на поверхности 1440 px
(1152/960/720 CSS px). Это проверка компоновки, не автоматизация меню
масштаба конкретного настольного браузера. Дополнительно тёмная тема.

Скриншоты `before_*` получены на физически сохранённом HTML TASK141 до
правок; `after_*` — на настоящем приложении TASK142 с той же синтетической
диагностикой. Чужие программы и изображения-имитации не использовались.
Полные результаты локальных запусков и GitHub CI указаны в описании PR.
