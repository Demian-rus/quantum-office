# TASK148 — полноценное редактирование схем и графиков

База: `7a12cd48225b0b1bdf85323a41be7f76afe95110` (TASK147 / PR #132).
Ветка: `feat/task148-visual-editor-functional-upgrade`. Только Draft PR;
merge требует отдельного разрешения владельца.

## Изменения

A. Построение протягиванием хранит отдельный черновик до pointerup.
Минимальное движение — 4 экранных пикселя плюс ненулевая геометрия после
привязки. Одиночные клики не расходуют лимит/Undo. Точка и подпись работают
кликом; pointercancel/lostpointercapture откатывают незавершённое действие.
Выбор проверяет линии/пружины, реальные многоугольники, окружности и
поворот. Сначала проверяются видимые объекты в обратном порядке отрисовки;
пустой контур можно переместить за внутреннюю область, только если там
нет другого видимого объекта. Подписи выбираются по настоящему SVG-тексту.
Команды переднего/заднего плана сохраняют порядок массива QWORK.

B. У объектов есть необязательный style: stroke/fill/text (#RRGGBB),
width (0.5–12). Заливка доступна замкнутым фигурам. Есть компактная палитра
и пользовательский цвет. Линия стрелки и наконечник имеют один цвет;
SVG-маркеры получают namespace содержимого, чтобы разные иллюстрации
одного PDF не использовали чужие цвета. Поддерживается общий rotation,
числовой ввод, маркер мышью, +15/+45/+90 и выравнивание бруска по углу
выбранной плоскости. Поворот происходит вокруг центра, размеры не меняются.

В обоих редакторах работают рамка, Shift+клик, Ctrl/Cmd+A на холсте,
групповое перемещение/удаление/оформление и Escape. Каждая групповая
операция — один Undo. Выделение, маркер вращения и рамка не сериализуются.

C. Старый pulley остаётся неподвижным блоком. Новый movablePulley имеет
две поддерживающие ветви и нижнее крепление груза через центральную ось;
у неподвижного подвес проходит через ось вверх. Геометрические точки
привязки учитывают поворот. Нити остаются самостоятельными объектами rope.
Обновлены композиции; добавлена готовая система с подвижным блоком.

D. Координатные пресеты: первая четверть, положительный X/двусторонний Y,
математическая система и произвольные диапазоны. Диапазоны используют
существующие xmin/xmax/ymin/ymax. Независимые примитивы графика хранятся в
необязательном graph.elements: point/line/arrow/polyline/text/function.
Отрезки не соединяются друг с другом; ломаная завершается кнопкой/Enter,
Escape отменяет черновик. Функции имеют собственные коэффициенты и стили.
Инструмент «Точка» создаёт независимый объект; «Точка шаблона» сохраняет
прежнее построение через points/connected. Старые
points/connected/smooth/curveFamily/curve продолжают работать;
для старой линии и функции предусмотрены отдельные lineStyle/curveStyle.

Математические координаты не зависят от размера холста. Изменение диапазона
не выбрасывает независимые объекты; интерфейс предупреждает об их выходе
за видимую область. Старые points сохраняют строгую проверку диапазонов:
сужение, обрезающее такие точки, отклоняется с сообщением.

## Совместимость и пределы

QWORK остаётся version 1: только необязательные дополнительные поля.
Старые документы без оформления используют прежние цвета. Импорт
проверяет координаты, типы, число вершин, коэффициенты и оформление;
небезопасные цвета и некорректные толщины отклоняются. QDOC, QDIAG, QBOOK,
QWBANK, Writer, Sheets и данные учеников не меняют схемы.

Лимиты: 60 объектов схемы; 40 старых точек и 60 независимых объектов графика;
2–40 вершин одной ломаной; история редактора — 30 операций. Нити имеют
геометрические точки привязки, но не постоянные ограничения: при дальнейшем
движении блока отдельная нить автоматически за ним не следует. Нет
физического симулятора. Поворот вершинного многоугольника при редактировании
отдельной вершины преобразуется в координаты вершин без потери положения.
Свойства и действия размещены в прежней компоновке TASK147.
