# TASK110 — Пропорциональный Writer и варианты диагностик

## Исправление компоновки

После TASK106 рабочая ширина диагностики была увеличена до 1540 px, а поля редактора и карточки растягивались почти на всю доступную область. Это ухудшало читаемость и не использовало пространство для новых возможностей. TASK110 заменяет такую растяжку функциональной компоновкой.

- **Центральная рабочая колонка** ограничена максимумом 880 px: формулировки, ответы, оценивание и редактор сохраняют нормальные пропорции, а поля не становятся чрезмерно широкими.
- **Слева — навигатор по темам** с количеством вопросов. При проведении дополнительно отображает количество оценённых и прогресс каждой темы. Нажатие переходит к соответствующему разделу; в пошаговом режиме открывает его первый вопрос. Для конструктора добавлено единое действие «Свернуть все / Развернуть все» — оно отличается от управления отдельным разделом.
- **Справа — информативный обзор** без повторения верхних кнопок: в конструкторе распределение по типам, количество вопросов, разделов, баллов и замечаний. Во время занятия — процент результата, оценённые/оставшиеся вопросы и количество каждой оценки.
- Между колонками остаются умеренные отступы. На среднем экране сохраняется навигация и центр, а узкий экран получает компактную горизонтальную навигацию по разделам. Обычная A4-страница Writer не затронута.
- Удалена лишняя кнопка перехода в библиотеку из конструктора, поскольку библиотека уже есть в верхнем меню. Управление шаблонами и QDIAG остаётся в существующих местах.

## Новая функция: варианты А–Г

В конструкторе добавлен сворачиваемый инструмент «Варианты проверочной работы». Для текущей диагностики можно указать:

- 2, 3 или 4 варианта (А/Б/В/Г).
- Использовать все задания либо фиксированное число из каждого непустого раздела.
- Ключ генерации для воспроизводимого распределения и перемешивание вариантов ответа в тестах.

Показываются состав и сумма баллов для каждого варианта. Каждая кнопка «Скачать вариант .qdiag» создаёт отдельный документ. **Исходные вопросы, ученики, результаты и история не изменяются.** В скачанные варианты не включаются имена учеников или оценки. Правильные варианты ответов остаются правильными после перемешивания.

Если заданных вопросов недостаточно для выбранной выборки, либо отсутствует ключ, генерация отклоняется с понятным сообщением. При использовании всех заданий разные варианты отличаются порядком вопросов. При ограниченной выборке разные варианты стремятся распределить разные задания по одинаковым темам, но не гарантируют уникальность между вариантами, если исходного материала недостаточно.
