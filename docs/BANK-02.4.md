## Обновление установленной версии

На машине владельца подтверждена версия 0.4.0 для текущего пользователя. Версия 0.4.1 собрана для Windows x64 тем же форматом NSIS с автономным Microsoft WebView2 и идентификатором `com.quantumoffice.desktop`. Путь к файлу в проекте — `evidence/bank-02.4/release/Quantum Office_0.4.1_x64-setup.exe`.

1. Экспортируйте банк в QWBANK и сохраните открытые документы в отдельные файлы. Закройте Quantum Office и сохраните резервную копию папки `%APPDATA%\com.quantumoffice.desktop` целиком.
2. Запустите Setup 0.4.1 из той же учётной записи Windows. В окне обнаруженной установки выберите **Do not uninstall** и оставьте прежний каталог установки.
3. Откройте Quantum Office и проверьте банк, черновики и настройки. Сохраните резервные файлы до окончания приёмки.

Пакет Quantum Office локальный и без цифровой подписи. Ручное удаление прежней версии для сценария обновления поверх не требуется. Интерактивная проверка установки и запуска в отдельной Windows остаётся открытой. Установщик в рабочем профиле владельца не запускался.

## Проверки

Сборка HTML и ZIP выполняется через `npm run build`. Браузерный сценарий и проверка фактического PDF запускаются последовательно.

```powershell
node tests/bank023_browser.cjs --bank-02.4
python tests/bank023_pdf_check.py --bank-02.4
```

Проверка PDF требует PyMuPDF, Pillow и материалы предыдущей редакции в `evidence/bank-02.3/`. Проверяются векторный набор, непрозрачность и чёрный цвет текста, программа встроенного шрифта Caveat, подпись на каждом листе, центр нижнего номера, положение подписей сил, шкала времени и геометрия BANK-02.3.

Для проверки данных фактический нативный код 0.4.0 записал синтетическое задание с вложением и постоянным номером, черновик и параметры панелей во временный каталог. Код 0.4.1 прочитал сохранённое состояние и добавил задание с полями `title`, `tags`, `publishing`. Сравнение выполнено без обращения к рабочей базе. В пакете проверены целостность NSIS, версия и архитектура приложения, ветка установки поверх и действительная подпись Microsoft у встроенного WebView2. Журналы хранятся в `evidence/bank-02.4/logs/`.
