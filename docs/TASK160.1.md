Целевой PR: `fix/task158-shared-spread-header-qx`. Merge в main запрещён.

## Изменено

- В формате booklet ответ остаётся вне `.qw-task-flow`, следующим grid-элементом.
  Высоту flow определяет естественный поток вместе с float-рисунком.
  Так ответ не должен пересекать длинное условие либо изображение.
- Автоматический выбор боковой / нижней иллюстрации использует измеренный
  текстовый блок в ширине, оставшейся после иллюстрации.
- Нижняя иллюстрация центрирована по области условия, графику разрешена
  увеличенная ширина. Приоритет — читаемые подписи.
- Нативные HTML-таблицы из условия переносятся под весь текст и
  центрируются. ВАЖНО: первоклассной структуры таблиц QWORK пока нет;
  HTML-таблицы добавляются в тестовый DOM, не через пользовательское поле
  (поле экранирует HTML).
- Оси графиков используют отдельные заполненные наконечники. Стержень
  заканчивается у основания стрелки, SVG marker-end на осях исключён.
- QX: настоящий встроенный Caveat, 15pt, чёрный, без обводки и подложки.
- Нумерационный квадрат уменьшен до 8mm; шрифт body по умолчанию 10pt.
