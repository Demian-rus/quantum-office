# TASK116 — План повторения по темам для группы

## Цель
В сводном журнале TASK115 преподаватель видит результаты учеников, но не видит,
какие **темы** требуют повторения чаще всего. TASK116 добавляет компактный план
повторения в существующий журнал, не меняя трёхколоночную компоновку диагностики
и не копируя действия в боковые панели.

## Как работает
- Для каждого ученика берётся **последняя по дате** сохранённая проверка с оценкой.
- По темам этой проверки определяется результат ниже справочного порога **60%**.
- Карточка темы показывает два **целочисленных показателя**:
  сколько учеников получили менее 60% и у скольких в последней проверке
  эта тема вообще была **оценена**. Неоценённое и отсутствующее не означает
  «не знает» и не ухудшает статистику.
- Если один раздел с одинаковым названием встречается дважды в одной
  проверке, ученик учитывается один раз; для определения необходимости
  повторения используется более низкий результат.
- Сортировка: число учеников, которым нужна тема, затем доля среди
  учеников с оценкой по теме, затем русское название.
- Нажатие на карточку фильтрует уже существующую таблицу учеников;
  повторное нажатие снимает фильтр. Фильтр «Нужна проверка знаний»
  продолжает работать совместно с фильтром темы.
- Показаны первые шесть тем, остальные можно развернуть. Отдельный
  экспорт CSV содержит полный план и имена учеников для повторения.
  Файлы CSV экранируют формулы Excel/Sheets.

## Методические ограничения
- Нет «среднего процента класса» по работам разного состава или сложности.
- Совпадение названия темы ещё не доказывает одинаковый набор заданий:
  показатели используются как ориентир для педагогического планирования.
- Не создаются и не изменяются оценки или задания; данные ученика не
  передаются в облако, экспорт выполняется только по явному нажатию.
- Сохранение QDIAG/QDOC, ограничение журнала и текущая структура хранения
  не меняются.
