## Референс пользователя
19 ноября 2026: файл `2.pdf` — одна вертикальная страница A4 с заданиями по всей ширине (8 страниц в представленном образце); файл `1.pdf` — альбомные листы A4, на каждом листе две отдельные текстовые полосы, читаемые как левая и правая вертикальные страницы (7 физических листов / 14 логических страниц в примере).

Фирменные элементы чужого материала не переносить. В Quantum Office по умолчанию оставить компактную типографику QX и собственную нумерацию.

## Вёрстка
- Новый необязательный `printSettings.landscapeLayout`: `spread` (по умолчанию при выборе landscape) или `wide` (предыдущая альбомная реализация). Старые QWORK v1 без поля не изменяются.
- Книжная A4 — прежняя однополосная печать.
- Альбомная `wide` — одно содержимое на физическом листе 297×210 мм.
- Альбомная `spread` — физический лист 297×210 мм, две самостоятельные логические страницы 148,5×210 мм слева направо, внутренняя печатная ширина каждой 130,5 мм. Разбиение по заданиям происходит до объединения двух страниц в физический лист.
- В PDF-превью отображается число физических листов и логических полос. Формат PDF и размер страницы по-прежнему определяются A4 CSS `@page`, изображения и MathML сохраняются векторными, если исходник — собственный SVG.

## Банк заданий
- В каждой записи личного QWBANK появилась кнопка «Редактировать».
- Отдельное окно позволяет менять условие, ответ, критерии, комментарий/решение, тип, наличие ответа и метаданные (предмет, класс, экзамен, год, часть, номер, сложность, тема, подтема, происхождение).
- Для графика и схемы используется существующий полноценный визуальный редактор; редактирование можно отменить или применить, сохраняя остальные незаписанные поля черновика.
- Растровое изображение (PNG/JPEG/WebP) можно заменить. Редактирование индивидуальных примитивов растрового PNG невозможно — для этого нужно создать новый SVG-рисунок в редакторе схем.
- Сохранение изменяет ту же запись банка по ID; открытая работа QWORK не меняется. «В банк» закрывает без сохранения. Импорт/экспорт QWBANK v1 сохраняет совместимость.
- Содержание банка хранится в localStorage; резервный экспорт в файл остаётся необходимым. Автоматическая перезапись QWORK из банка запрещена, чтобы не потерять пользовательские правки в составленных вариантах.

## Ограничения
Точный динамический перенос таблиц и длинных многострочных формул в узких полосах зависит от текста и текущего механизма разбиения. Если печать обнаруживает слишком широкую формулу, она выдаёт диагностическую ошибку вместо невидимого обрезания. Существующие задания с большой картинкой можно печатать в режиме `wide`.

Никаких merge без разрешения владельца.
