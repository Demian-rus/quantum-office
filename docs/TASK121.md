# TASK121 — Иллюстрации в вопросах и ответах

## Для преподавателя
В **Тексты → Диагностика → Конструктор** каждая развёрнутая карточка
получает два независимых медиаблока:
- «Иллюстрация вопроса» — видна при проведении без дополнительных действий.
- «Иллюстрация ответа» — видна только после нажатия «Показать ответ».

В каждом блоке доступны:
- загрузка PNG/JPG/WebP до 12 МБ;
- вставка скрина из буфера клавишами Ctrl+V в блоке или прямо в соответствующем текстовом поле;
- кнопка «Вставить скрин» (прямое чтение clipboard при наличии разрешения браузера, иначе подсказка Ctrl+V);
- рисование с карандашом, ластиком, цветом, толщиной, очисткой и 12 шагами отмены;
- подпись, размер компактный/обычный/широкий, увеличение изображения;
- замена и удаление привязки изображения к карточке.

Компактный список не разворачивает картинки: показывает лишь индикаторы иллюстраций.
Размеры превью ограничены, пропорции сохраняются, при печати используется `object-fit:contain`.

## Хранение
- Изображения хранятся локально в IndexedDB как Blob; в QDIAG и пользовательских
  шаблонах — только безопасные ID и параметры отображения.
- При загрузке изображение приводится к 1600 пикселям по длинной стороне, с фоном
  белого цвета и WebP-сжатием, без сетевых запросов.
- Копии вопросов могут ссылаться на один и тот же asset ID, удаление привязки
  из одной карточки не удаляет картинку у другой.
- Автоматическое удаление исходных blob пока **не включено**: это потребовало бы
  проверять ссылки во всех локальных книгах, шаблонах и версиях. Удаление привязки
  из карточки не удаляет ассет из IndexedDB. Это безопасный компромисс первой версии.

## Переносимые файлы
- Если иллюстраций нет, старые .qdiag, .qtpl, .qbank формируются и открываются без изменений.
- Если медиа есть, обычные действия «Сохранить» и «Скачать библиотеку» выдают
  архивы .qdiagx, .qtplx, .qbankx — JSON-манифест и бинарные изображения.
- При импорте архивы проверяются, картинки кладутся в IndexedDB под новыми ID,
  ссылки в вопросах переписываются. Файл .qdiagx открывается с подтверждением
  замены текущей диагностики.
- Ограничение ZIP-импорта 60 МБ; до 240 медиа-объектов в архиве.
- В отсутствие IndexedDB редактирование медиа недоступно, текстовые диагностики
  продолжают работать.

## Границы TASK121
Изображения не редактируются прямо в Quantum Studio. Встроенный холст предназначен
для быстрых схем и рисунков, не для профессиональной обработки фото.
Первый этап позволяет по **одной иллюстрации** к вопросу и к ответу.

## Проверки
- `tests/task121.test.js`: нормализация, безопасные ссылки, копии карточек,
  сохранение ссылок в пользовательских шаблонах и банке.
- `tests/task121_browser.cjs`: загрузка картинки, имитация вставки скриншота,
  сохранение подписи, компактный режим, скрытый ответ, увеличение, рисунок,
  QDIAGX roundtrip, QTPLX экспорт, адаптивность 1600/1100/650/390.
- `npm test`, `npm run build`, общая Chromium CI.
- Ничего не меняет в таблицах, презентациях и фоторедакторе.
