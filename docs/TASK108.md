# TASK108 — Управление собственными шаблонами Quantum Writer

## Возможности

В библиотеке диагностик у созданных пользователем шаблонов доступны **Изменить**, **Копировать**, **Просмотреть**, **Открыть**, **Удалить**.

**Изменить** открывает отдельный редактор, где можно независимо изменить название, описание, предмет, класс и цель. По умолчанию вопросы остаются неизменными. При включении явной опции «Обновить вопросы шаблона из текущей диагностики» текущий набор вопросов заменяет сохранённый: требуется дополнительное подтверждение, с предупреждением о резервной копии `.qtpl`.

**Копировать** создаёт самостоятельный шаблон со своим ID и названием с суффиксом «копия». Исходный шаблон не меняется. Изменение скопированного шаблона никак не затрагивает оригинал.

Сохранение новой записи с уже существующим названием отклоняется и предлагает отредактировать старую вместо создания дубликата. Контроль применяется также при переименовании. Проверяется лимит 30 пользовательских шаблонов.

Ни при изменении метаданных, ни при явном обновлении вопросов в шаблон не попадают имена учеников, оценки или журнал диагностики. Текущий Writer и собственно текущая диагностика при редактировании или копировании шаблона не изменяются.

Все собственные шаблоны по-прежнему могут быть перенесены между разными HTML-файлами через экспорт/импорт `.qtpl`. Редактор адаптивен для широких и мобильных экранов.
