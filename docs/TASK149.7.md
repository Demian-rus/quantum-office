## Воспроизведённый дефект рамки

До исправления `qwObjectBounds(ray/infiniteLine)` возвращал одну начальную
точку. Настоящие pointer events воспроизвели выбор всего луча рамкой только
вокруг начала. Выделение остальных объектов использует полное вхождение.

Теперь границы выбора вычисляются по уже существующему видимому отрезку
`qwExtendedSegment`, с учётом поворота. Для перемещения отдельно сохранено
прежнее ограничение по хранимой опоре: видимые края не блокируют перенос.
Модель, связи, SVG и QWORK не менялись. Реальные события проверяют оба типа:
рамка вокруг всей видимой линии, исключение рамки только вокруг опоры и
части линии, групповой перенос с прямоугольником, объектный Undo, применение,
Undo/Redo всей правки. Параллельная/перпендикулярная обновляются после
редактирования опоры; Undo возвращает геометрию.

## Автономные артефакты

Независимая пересборка **точной исходной базы** дала HTML, побайтно равный
опубликованному внешнему HTML. Однако исходный опубликованный ZIP содержит
CRLF, внешний HTML — LF. CRC ZIP корректен, после нормализации строки
совпадают полностью. Это объясняет прежнее расхождение, но не является
побайтовой идентичностью исходных файлов.

- Исходный внешний HTML SHA-256:
  `9a9f3c5f3fa05405ad7f5db0c745dcd8cfdf47c691c4fb631be559bbb0edc180`.
- Исходный вложенный HTML SHA-256:
  `1c1e2f03edf300a7a0f6a9a9fb232464f50c626a40906852e56e4631e68f78d3`.
- Новый HTML и `dist/index.html` SHA-256:
  `3ccaa3865593265d69e25b5499f8510fcd9938c9f560ef95e18b89422662ae1e`.
- Новый ZIP SHA-256:
  `31d518d5c3dd0f8dcd25848a530caba2e39f49e8b90f336cce5660dc1e752795`.

Build нормализует CRLF → LF и фиксирует UTC-дату ZIP. Два последовательных
build, CRLF-копия исходников и build в Pacific/Honolulu дают одинаковые
HTML/ZIP. `zipfile.testzip()` проверяет CRC; вложенный HTML точно совпадает
с обоими внешними HTML. Это независимо проверяется новым Python-сценарием.

При заблокированной сети приложение открыто через file://, все семь
QWORK сохранены кнопкой, импортированы в новый проект и сравнены целиком
(включая ID/порядок/ответы/настройки/построения). Ошибочный JSON отвергнут
атомарно. Предпросмотр готов и реальный векторный PDF подготовлен offline;
HTTP-запросов 0. Форматы других редакторов/данные учеников не менялись.
