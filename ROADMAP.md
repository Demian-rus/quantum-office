# Quantum Office — roadmap and acceptance gates

**IMPORTANT:** read [`docs/PROJECT_CONTEXT.md`](docs/PROJECT_CONTEXT.md) first for current owner decisions, UI direction, limitations, and handoff. The historical checkboxes below are not an authoritative live status page.

## Product architecture (fixed decision)

- ONE application and installer for Windows and macOS.
- On launch, a workspace dashboard with editors: **Sheets**, **Writer**, **Slides**.
- On choosing an editor, it receives the entire working area. Editor switching remains in a compact top-level navigation, alongside familiar File / Edit / Insert / View concepts.
- Extensions can be added later without spawning multiple apps or duplicating file storage.
- Offline-first, no Microsoft activation, subscriptions or external API required for editing local files.
- Not a visual clone of Microsoft Office. Interface and workflows can be redesigned, but data compatibility must be verified rather than assumed.

## Workflow rules

One issue → one measurable change → tests and independent evidence. Do not declare "full Office" ready until all major editor functions pass real acceptance scenarios. Do not quietly downgrade or discard unsupported file features. Keep the production branch green. Do not overwrite the user's data to improve a demo.

## TASK 019 — Template navigation and Excel-style selection (2026-10-28)

- Template catalogs for Sheets, Writer, Slides under each launcher tile; Writer and Slides must stay clearly disabled until implemented.
- User-reference weekly schedule template with day bands and payment columns; extra finance and partnership sheets. Do not invent pupil data.
- Fixed separate header overlays that remain stationary during vertical scrolling.
- Click column letters to select entire column; row numbers entire row; top-left triangle all sheet. Current engine limit 2000×100, large bulk edits are bounded to protect memory.
- No separate sheet rename icon: double-click tab to rename, `+` to create.
- Next critical visual parity: real merged cells, individual border sides/styles, and more text layout options. Basic all-edge thin borders and text wrap have been added in TASK 020; full Excel styling still remains incomplete.
